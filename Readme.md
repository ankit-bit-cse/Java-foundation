# ☕ Java in 10 Days

A beginner-friendly **10-day Java learning program** designed to take you from the basics of Java to Object-Oriented Programming, Collections, Exception Handling, and a small final project.

The course focuses not only on writing Java code, but also on understanding **Java terminology, concepts, execution flow, and why things work the way they do**.

Explanations are provided in **Hinglish (Hindi + English)** to make the concepts easier to understand.

---

## 🎯 Goal

By the end of these 10 days, you should be able to:

* Understand Java fundamentals
* Write and execute Java programs
* Understand variables and data types
* Use conditions and loops
* Work with arrays and strings
* Create and use methods
* Understand Object-Oriented Programming (OOP)
* Work with classes and objects
* Understand inheritance and polymorphism
* Use interfaces and abstraction
* Handle exceptions
* Work with Java Collections
* Build a small Java project
* Answer basic Java interview questions

# 📝 Daily Practice Rule

For every topic:

1. Understand the concept
2. Write the example yourself
3. Run the program
4. Change the code
5. Predict the output before running
6. Solve practice problems
7. Review mistakes

**Don't just copy-paste code.**

The objective is to make you comfortable writing Java code independently.
